- (decision) Stakes: internal; Form-factor: web-responsive (desktop + mobile warehouse 390px). Inherit existing ShopLite UI system (Tailwind CSS v4 + Be Vietnam Pro + indigo-600/slate/rose-600/emerald + rounded-2xl cards + existing Button & OrderStatusBadge). DESIGN.md captures existing tokens + delta only.
- (decision) Surfaces in IA: /admin/login (Passcode gate + unconfigured 503 state), /admin/orders (Staff order ops queue with URL status filter tabs + counts, search, inline reserved/available stock indicator, 1-step primary action, cancel reason dialog, restock confirmation), /orders/[id] (Enhanced customer detail with 4-step Order Timeline + manual Refresh button + CancelOrderButton only on pending), and dynamic stock consistency across /, /products, /products/[slug], /checkout.
- (decision) Color delta & anti-illusion coding: reuse existing OrderStatusBadge colors; add inline reserved-stock indicator with 3 semantic tiers (emerald >5, amber 1-5, rose 0 with explicit 'Đã giữ X cho đơn này' text so staff never confuse 0 available with out-of-stock); add amber restock-pending badge ('Chờ nhận hàng hoàn') vs emerald restocked badge ('Đã hoàn kho'). Always pair color with icon + text (never color-only).
- (decision) Interaction rules: single-step primary CTA button per order (no arbitrary status dropdown), minimum 44px touch targets on 390px mobile, cancel modal with 3 editable quick-reason chips + mandatory note <=200 chars + explicit non-restock warning for shipping orders, optimistic locking expectedStatus on every status mutation, 401 -> redirect /admin/login?expired=1, 409 -> role='alert' banner + auto-refresh.
- (decision) Key-screen 1:1 HTML mockups to produce and promote to mockups/: (1) admin-orders.html (desktop + mobile 390px view showing filter tabs, reserved stock inline tiers, single-step CTA, cancel reason modal, and cancelled shipping restock card), (2) order-detail-timeline.html (customer /orders/[id] showing 4-step progress timeline + manual Refresh button + cancelled with reason alternate state), (3) admin-login.html (standard login + unconfigured 503 fail-closed state).
- (event) spines finalized (passed independent 8-category UX Spine Rubric Review; resolved 3 high, 5 medium, 6 low findings; DESIGN.md & EXPERIENCE.md set to status: final)
